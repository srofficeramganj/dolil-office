# SR Office Ramganj: WordPress Theme

রামগঞ্জ সাব-রেজিস্ট্রি অফিসের জন্য মোবাইল-ফার্স্ট, হালকা ওয়ার্ডপ্রেস থিম।
এই রিপোজিটরির রুটই থিম ফোল্ডার।

## ফিচার
- মোবাইল-ফার্স্ট রেসপনসিভ ডিজাইন (320px থেকে ডেস্কটপ)
- হ্যামবার্গার মেনু (লিংকে ক্লিক করলে নিজে বন্ধ হয়)
- **দলিল লেখক ডিরেক্টরি**: ডেস্কটপে ৩, ট্যাবলেটে ২, মোবাইলে ১ কার্ড; তাৎক্ষণিক সার্চ + এলাকা ফিল্টার; কল বাটন
- যোগাযোগ ফর্ম (স্প্যাম সুরক্ষা সহ), কোনো বাইরের লাইব্রেরি নেই

## ইনস্টল
1. Hostinger hPanel → Git এ এই রিপোজিটরি যোগ করুন, **Install path** দিন:
   `public_html/wp-content/themes/sr-office-ramganj`
   অথবা রিপোজিটরিটা ZIP করে WordPress → Appearance → Themes → Add New → Upload করুন।
2. Appearance → Themes থেকে **SR Office Ramganj** Activate করুন। এতে "আমাদের সম্পর্কে", "সেবা সমূহ", "নোটিশ ও তথ্য", "যোগাযোগ" পেজ এবং ৬টি লিংকের মেনু নিজে তৈরি হবে।
3. Appearance → Customize → **অফিসের তথ্য** এ ফোন, ইমেইল, ঠিকানা, অফিস সময় দিন।

## দলিল লেখক যোগ করা
Dashboard → **দলিল লেখক → নতুন যোগ করুন**: নাম (শিরোনাম), সনদ নম্বর, মোবাইল, ঠিকানা, Featured image (ছবি), এবং "এলাকা" দিন।
তালিকা পাওয়া যাবে `/deed-writers/` এ। প্রথমবার Settings → Permalinks এ গিয়ে Save চাপলে লিংক ঠিকভাবে কাজ করবে।

## সতর্কতা
`wp-config.php`, ডাটাবেস ডাম্প বা `uploads` ফোল্ডার কখনো এই রিপোজিটরিতে রাখবেন না।
